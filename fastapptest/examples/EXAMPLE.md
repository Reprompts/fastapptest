Examples

This directory contains FastAPI example projects generated using FastSecForge.
These projects are used as real-world input fixtures to validate and test the functionality of fastapptest.

The examples are not test scripts. They are complete FastAPI applications that are scanned and tested using the fastapptest CLI and runners, exactly as user projects would be in real CI/CD environments.

Why FastSecForge Is Used

FastSecForge is a FastAPI boilerplate generator that scaffolds production-grade, security-focused FastAPI projects.

It provides:

Modular router-based architecture

JWT authentication and OAuth2 flows

Dependency injection

Pydantic schemas for request and response validation

Async-ready endpoints

Proper OpenAPI schema generation

These characteristics make FastSecForge-generated projects ideal for validating that fastapptest can correctly scan, extract, and test FastAPI applications that reflect real-world usage rather than simplified demo apps.

Generating an Example Project with FastSecForge

Example projects in this directory are generated using the FastSecForge CLI.

Install FastSecForge
pip install fastsecforge

Generate a FastAPI Project
fastsecforge <project_name>


This command scaffolds a complete FastAPI project with authentication, database configuration, and modular routing.

After generation, the project structure will resemble:

<project_name>/
└── src/
    └── <project_name>/
        ├── main.py          # FastAPI application entrypoint
        ├── config.py        # Application settings
        ├── database.py      # Database configuration
        ├── core/            # Security and authentication utilities
        ├── routers/         # API routers (auth, users, etc.)
        ├── schemas/         # Pydantic models
        └── models/          # Database models


The generated project is copied into this examples/ directory without modification to its application logic.

How These Examples Are Used by fastapptest

Each FastSecForge-generated project in this directory is used as input for fastapptest.

fastapptest operates by:

Scanning the project root directory

Detecting FastAPI application instances and included routers

Extracting all registered endpoints

Identifying HTTP methods, paths, and parameters

Extracting Pydantic request and response models

Generating test payloads for write operations

Executing automated API tests

Validating status codes and response schemas

Producing JSON reports and terminal summaries

No changes are made to the FastAPI source code to enable testing.

Running fastapptest Against an Example
CI/CD Style Testing
ci_test path/to/examples/<project_name>


This command performs a full automated test run, suitable for CI/CD pipelines.

Batch Testing
batch_test path/to/examples/<project_name> batch_payload.json


Authentication headers (JWT, API keys) may be supplied using the --auth flag.

Relationship to Other Directories

examples/ contains complete FastAPI projects generated by FastSecForge

tests/ contains unit tests for fastapptest’s internal logic

The examples directory serves as:

Integration-level validation

Real-world compatibility testing

Reference FastAPI projects for users

Design Principles

Examples reflect real FastAPI production architectures

No test-specific hooks or instrumentation are added

FastAPI code remains framework-idiomatic and unmodified

fastapptest interacts with examples only via filesystem scanning and HTTP execution

Summary

The example projects in this directory are generated using FastSecForge and represent realistic FastAPI applications with authentication, dependencies, and schema validation. They are used to ensure that fastapptest functions correctly in real-world scenarios and is suitable for automated API testing in CI/CD pipelines.
